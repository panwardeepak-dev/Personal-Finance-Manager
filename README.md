# Personal Finance Manager

A CLI-based Personal Finance Manager built with Python.

## Features

- Add Income
- Add Expense
- View Transactions
- Search Transactions
- Filter Transactions by Category
- Calculate Total Income
- Calculate Total Expenses
- Calculate Current Balance
- Export Data to CSV
- Store Data in JSON

## Technologies Used

- Python
- OOP
- JSON
- CSV
- File Handling
- Exception Handling
- Git & GitHub
